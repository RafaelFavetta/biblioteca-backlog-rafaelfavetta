# Biblioteca Comunitária Saber Livre

Backlog inicial do sistema web da Biblioteca Comunitária Saber Livre, elaborado para a atividade de Gestão Ágil de Projetos de Software.

O sistema atende visitantes, leitores, bibliotecários e a coordenação. O backlog usa épicos, estórias de usuário, critérios de aceite testáveis e uma Sprint 1 orientada à consulta do acervo e ao empréstimo de exemplares.

## Épicos

- E1 — Acervo
- E2 — Leitores
- E3 — Empréstimos e devoluções
- E4 — Reservas
- E5 — Multas e bloqueios
- E6 — Notificações
- E7 — Relatórios

As regras de negócio adotadas são as definidas no enunciado da atividade. O planejamento e a hierarquia das issues estão no GitHub Project vinculado a este repositório.
